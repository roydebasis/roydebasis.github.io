## 🔧 Local Development

To run this portfolio locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://://github.com/roydebashish.github.io.git
   ```
2. Navigate into the project directory:
   ```bash
   cd roydebashish.github.io
   ```
3. Open `index.html` directly in your browser or serve it using a local development server (such as VS Code Live Server).
